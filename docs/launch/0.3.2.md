## Reddit body

<!-- reddit-body:start -->
Maintainer disclosure: I built and maintain this free MIT-licensed project.

`mini-code-agent-langgraph` is a compact CLI/REPL for developers who want to inspect a coding-agent loop rather than hide it behind a large UI. A coding run cannot reach `Submitted` until the user-selected test command passes against the current workspace fingerprint. It also keeps redacted resumable trajectories, invalidates stale verification after resume, and provides HMAC-authenticated conflict-aware Undo.

The first run needs no provider or API key:

```bash
python -m pip install mini-code-agent-langgraph==0.3.2
mca demo
```

The new deterministic offline suite passes 11/11 runtime-policy cases: nine verified submissions and two expected refusals, with zero unexpected submissions and zero unrelated changes. This is not a model-quality or SWE-bench claim; scripted local decisions exercise the runtime policy and lifecycle boundaries.

Repository: https://github.com/wusuiling-if/mini-code-agent-langgraph

I am looking for technical criticism of the verification boundary, trajectory/resume format, Undo threat model, sandbox ergonomics, and the current LangChain/LangGraph coupling.
